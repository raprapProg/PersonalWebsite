About

FIG. 01 — PORTRAIT

I'm a software engineer who likes taking a project from a rough idea to something people actually rely on. My background is in backend systems, but I spend just as much time in CSS — I think good software should feel considered from the API down to the interface.

Before going independent, I spent four years building internal tooling and customer-facing products at a logistics startup, where I learned that the best code is the code a team can still understand a year later.

When I'm not at the keyboard, I'm usually rebuilding something mechanical, reading about type design, or losing to my sister at chess.
